# 第六讲　机器人行动前，需要先想象未来吗？

夹爪碰到了密封袋的滑扣。沿着袋口一拉，可能把袋子打开，也可能把整只袋子拖走。机器人可以从过去的录像里学会怎么拉，也可以在动手前提出几种拉法，预测后果再选一种。五篇论文都借用了视频生成模型，预测到的未来却在不同的时刻改变动作。

## 先看一段动作是怎么来的

| 阅读顺序 | 执行时怎样得到动作 |
| --- | --- |
| [Fast-WAM](./01-fast-wam.md) | 编码当前画面一次，随后直接生成动作。未来视频在训练时提供监督。 |
| [Motus](./02-motus.md) | 从光流学习潜在动作。同一模型既可直接生成动作，也可联合生成视频和动作。 |
| [LingBot-VA](./03-lingbot-va.md) | 先预测视觉变化，再反推控制。异步运行时还要重估正在执行的那段动作会停在哪里。 |
| [DreamZero](./04-dreamzero.md) | 在一个时间段内联合去噪视频和动作，下一轮将实拍结果写回视觉历史。 |
| [Cosmos Policy](./05-cosmos-policy.md) | 直接执行时取出策略动作；规划时先提出多种拉法，分别预测终点，再按价值排序。 |

## 一次控制循环，三种时间尺度

一轮去噪、一步机器人控制和一次策略更新分别在数什么？记 $K$ 为模型内部的去噪迭代次数，$H$ 为一次生成的动作步数，$h$ 为下一次更新前实际执行的步数。一次生成 30 步、底层以 30 Hz 运行，整段覆盖 1 秒。如果只执行前 6 步就重新观察，那么 0.2 秒后便有机会依据新画面调整动作，前提是模型能按时交出下一段指令。

给定当前信息 $C$，把未来视觉表示记为 $Z$、动作段记为 $A$。同一个联合分布可以写成 $p(A,Z\mid C)=p(Z\mid C)\,p(A\mid C,Z)$。这个等式允许先预测视觉未来再反推动作，也允许直接联合采样。要判断部署时究竟算了什么，还得看注意力能读到哪些输入、两种模态各做几轮去噪，以及新观测何时进入模型。

## 回到夹爪碰到滑扣的那一刻

在 Fast-WAM 里，未来画面的预测误差已经改变了提取首帧特征的权重。Motus 可以选择此时是否显式生成一段未来。DreamZero 让动作与画面一起逐步成形，每轮去噪都能更新两者。

LingBot-VA 和 Cosmos Policy 都在预测终点，但可以追问「这是谁的动作」。LingBot-VA 异步运行时估计**已经发出的动作**会把滑扣带到哪里，让下一段动作接得上。Cosmos Policy 规划时估计**还没发出的候选动作**各会把滑扣带到哪里，预测结果可以改变到底发出哪一段。
