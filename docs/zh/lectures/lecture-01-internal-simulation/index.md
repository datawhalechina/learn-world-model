# 世界模型的工作定义、历史与直觉

朋友从三米外扔来一个网球，你甚至还没看清球的旋转，手就已经移到了正确的位置。这不是反射，也不是运气，**你的大脑在那零点几秒里模拟了这颗球的飞行轨迹**，预测它会落在哪里，然后提前指挥肌肉行动。

世界模型就是这个机制的计算版本：大脑（或 AI）在内部维护的一张"世界运转规律"的草图，让行动者可以在真实出手之前先在脑子里把结果演一遍。

读完本讲，你应该能够判断一个系统预测的对象和消费预测的方式，区分渲染、模拟与规划，并用简洁的能力阶梯说明不同系统之间的差异。

本讲按问题出现的顺序展开：

- **工作定义**：先区分渲染器、模拟器与规划器，再用状态估计、转移、发射和预测查询描述一个世界模型提供的接口
- **思想来路**：从 Craik（1943）到预测编码与内模原理，理解“先在内部试验再行动”为什么不是新想法
- **价值与时代背景**：世界模型解决什么问题，以及视频生成、具身智能、自动驾驶为何在此时交汇
- **分类与路线图**：最后用四个时代和 L1-L5 能力阶梯整理已经见过的系统，并进入课程的项目主线
