# 제2강: 관측 인코딩과 잠재 동역학

Dreamer의 핵심 문제는 **지각(perception) 정보를 어떻게 압축할 것인가**와 **미래를 어떻게 예측할 것인가**라는 두 질문으로 나뉘며, 이번 강의는 이 두 질문을 차례로 다룹니다.

- **관측 인코딩**: 왜 압축이 필요한지, VAE의 인코더-디코더 구조, ELBO 손실 함수의 직관, CNN 인코더의 구조
- **잠재 동역학**: 가장 단순한 GRU에서 출발해 MDN-RNN의 불확실성 모델링을 거쳐 RSSM의 결정론적/확률적 이중 경로 설계에 이르는 과정

관측 인코딩을 읽고 P01을 완료한 뒤, 다시 돌아와 잠재 동역학을 읽고 P02를 완료하세요. 이렇게 번갈아 진행하면, 여러분이 이미 학습시키고 직접 살펴본 표현 위에서 동역학 모델이 동작하게 됩니다.
