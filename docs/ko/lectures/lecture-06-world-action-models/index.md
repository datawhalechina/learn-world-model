# 제6강　로봇은 행동하기 전에 미래를 상상해야 할까요?

그리퍼가 지퍼백의 슬라이더에 닿았습니다. 봉투 입구를 따라 당기면 지퍼가 열릴 수도 있고 봉투 전체가 끌려올 수도 있습니다. 로봇은 시범 영상으로 당기는 법을 배울 수 있고, 여러 동작을 제안해 각각의 결과를 예상해 본 뒤 하나를 고를 수도 있습니다. 다섯 논문은 모두 영상 생성 모델을 활용하지만 예측한 미래가 행동을 바꾸는 시점은 서로 다릅니다.

## 관측에서 실행까지 행동 구간 따라가기

| 읽는 순서 | 실행할 명령을 얻는 과정 |
| --- | --- |
| [Fast-WAM](./01-fast-wam.md) | 현재 영상을 한 번 인코딩한 뒤 바로 행동을 생성합니다. 미래 영상은 학습 목표로 사용합니다. |
| [Motus](./02-motus.md) | 광류에서 잠재 행동을 학습합니다. 같은 모델로 행동을 바로 생성하거나 영상과 행동을 함께 생성합니다. |
| [LingBot-VA](./03-lingbot-va.md) | 다음 영상 변화를 예측한 뒤 제어를 역으로 추론합니다. 비동기 실행 시에는 현재 행동이 끝날 위치를 먼저 추정합니다. |
| [DreamZero](./04-dreamzero.md) | 구간 안에서 영상과 행동의 잡음을 함께 제거합니다. 다음 구간을 위해 실제 관측으로 시각 이력을 갱신합니다. |
| [Cosmos Policy](./05-cosmos-policy.md) | 직접 실행할 때는 정책의 행동을 쓰고, 계획할 때는 여러 후보 행동의 종점을 예측하고 가치로 순위를 매깁니다. |

## 제어 루프에 등장하는 세 가지 시간 척도

$K$는 모델 내부의 잡음 제거 반복 횟수, $H$는 한 번에 생성하는 제어 스텝 수, $h$는 다음 갱신 전까지 실제 실행하는 스텝 수입니다. 30개 명령을 30 Hz로 실행하면 한 구간은 1초입니다. 앞의 여섯 스텝만 실행한 뒤 카메라를 다시 읽으면 0.2초 후에 새 관측을 반영할 기회가 생깁니다. 모델이 다음 명령을 제때 계산할 수 있어야 합니다.

현재 주어진 정보를 $C$, 미래 시각 표현을 $Z$, 행동 구간을 $A$라고 쓰면 $p(A,Z\mid C)=p(Z\mid C)\,p(A\mid C,Z)$입니다. 두 항을 함께 샘플링할 수도 있고, 영상 예측 후 역동역학으로 행동을 구할 수도 있습니다. 실제 실행 경로를 알려면 어텐션이 무엇을 참조하는지, 각 모달리티가 몇 번 잡음 제거를 거치는지, 실제 관측이 언제 다시 들어오는지를 살펴봐야 합니다.

## 그리퍼가 슬라이더에 닿은 순간으로 돌아가기

Fast-WAM에서는 미래 영상을 예측하는 훈련이 이미 첫 관측을 인코딩하는 가중치에 영향을 주었습니다. Motus에서는 실행 모드에 따라 미래 영상을 생성할지 선택할 수 있습니다. DreamZero에서는 매번 잡음을 제거할 때 영상과 행동이 함께 갱신됩니다.

LingBot-VA와 Cosmos Policy는 모두 종점을 예측합니다. 이때 누구의 행동에 대한 종점일까요? 비동기 LingBot-VA는 **이미 보낸 행동**이 슬라이더를 어디로 옮길지 추정해 다음 행동을 이어 갑니다. Cosmos Policy는 **아직 보내지 않은 여러 후보 행동**이 만들어 낼 종점을 추정해 실제로 보낼 명령을 고릅니다.
